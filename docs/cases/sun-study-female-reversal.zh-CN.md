# 孙学反转写作：从爽文模仿变成结构可控的女性反转叙事

## 谁会用

想写交易感强、节奏快、有反转，但不想照搬真人经历或制造事实指控的长文作者。

## 输入

一段关系或商业叙事素材，以及希望保留的数字、物件、交易和冲突。素材可以是虚构练习；涉及真人时必须把事实、推断和虚构分开。

## Skill 做了什么

1. 拆出数字、物件、交易与叙事权。
2. 先建立女主自己的账本和目标，不把她写成被动工具人。
3. 安排三次以上控制权转移，让“她以为在设局”与“她也被计算”同时成立。
4. 做事实边界、名誉风险和虚构标识检查。

## 输出

- 三个可验证的结构机关
- 6–10 个反转节拍
- 一篇完整女性视角长文
- 事实、推断、虚构的边界说明
