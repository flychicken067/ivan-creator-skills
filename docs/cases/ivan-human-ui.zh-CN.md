# Ivan Human UI：把“能用”改成“人一眼就懂”

## 谁会用

需要把 AI 生成页面交给同事或研发确认的产品负责人、设计师和前端开发者。

## 输入

一张功能齐全、但层级混乱、按钮过多、像“文字 PPT”的后台页面。

![修改前：信息拥挤、层级不清](../assets/human-ui-before.png)

## Skill 做了什么

1. 先识别用户此刻真正要完成的主任务。
2. 删除解释性噪音，保留一个主要动作。
3. 重排标题、正文、状态与按钮的视觉层级。
4. 检查点击路径、空状态、失败状态和真实数据边界。

## 输出

一个仍沿用原产品结构、但更像真实软件而不是 AI 展板的页面。

![修改后：主任务明确、操作路径更短](../assets/human-ui-after.png)

## 价值证据

- 原有业务结构没有被推翻。
- 用户第一眼能找到主要动作。
- 前后差异可直接由截图核验。
- 修改结果仍可继续交给研发实现，而不是一张无法落地的概念图。
