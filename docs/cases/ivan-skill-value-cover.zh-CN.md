# Ivan Skill Value Cover：让陌生人先看懂，再决定安装

## 谁会用

已经写好 Skill，但市场卡片只有名称和抽象描述、用户看不出价值的创作者。

## 输入

- 一份 `SKILL.md`
- 一个真实使用场景
- 使用前的麻烦与使用后的可见结果

## Skill 做了什么

1. 从说明书中提取“谁、在什么场景、遇到什么问题”。
2. 选择同一个人物和同一个任务，建立可比较的前后状态。
3. 把抽象能力翻译成可见结果，避免堆功能名和方法论。
4. 同时生成适合市场卡片与详情页的画面方案。

## 输出

![Skill 价值封面：用人物和结果说明价值](../assets/skill-value-cover.png)

## 价值证据

- 用户无需先读完整 `SKILL.md`。
- 画面回答“这个 Skill 对我有什么用”，而不只是“它叫什么”。
- 同一套价值叙事可复用到 YouMind、GitHub Release 和推广内容。
- YouMind 已显示 9 次安装；安装量不等同于活跃用户或付费用户。
