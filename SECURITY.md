# Security and privacy

This public repository must not contain employer, customer, partner, account, credential, or non-public product material.

Before opening an issue or attaching an example:

- remove API keys, tokens, account identifiers, private links, customer data, and local absolute paths;
- use public, fictional, or explicitly redacted inputs;
- describe an internal workflow generically rather than uploading company documents;
- treat generated covers and mockups as explanations, not runtime evidence.

If sensitive information is accidentally committed, do not only delete it in a later commit. Revoke exposed credentials first, then remove the material from Git history and affected releases.
