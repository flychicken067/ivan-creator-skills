# 中立的 Skill 封面叙事参考

这些案例只用于帮助理解封面结构，不是固定文案。优先使用用户自己的真实输入与输出；没有真实材料时，只能使用明确标注的公开资料或虚构演示数据。

## 公开软件说明书问答

- 人物：客服、运营或第一次使用软件的新同事
- 输入：用户临时提问，答案散落在公开帮助中心与更新日志中
- 输出：一句可直接使用的回答、操作步骤、适用版本和可点击来源
- 核心变化：从“翻十页也不敢确认”到“有出处地立即回答”

## 公开商品页面比较

- 人物：采购、产品研究员或独立创作者
- 输入：三个公开商品页面的价格、规格、截图与更新时间各不相同
- 输出：统一字段的比较表、页面截图、来源网址和抓取时间
- 核心变化：从“凭印象挑选”到“拿同一尺度的证据做决定”

## 虚构活动页面生成

- 人物：活动组织者、设计师或开发者
- 输入：一份明确标注为虚构的活动简报、图片素材和页面要求
- 输出：可预览、可批注、等待人工确认的活动页面草稿
- 核心变化：从“反复转述需求”到“围绕真实页面确认”

## 使用边界

- 不使用雇主、客户或合作方的未公开资料作为个人项目案例。
- 不把演示数据写成真实业绩、真实用户或真实商业结果。
- 封面只表达已经验证的输入、过程和输出，不替 Skill 承诺尚未实现的能力。
