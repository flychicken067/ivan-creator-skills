# 孙学反转写作

把一篇长文拆成“孙学”机关，再用女性第一人称写出反转文章：**她以为自己在试探孙哥、给关系定价，最后发现自己的试探、身体成本和情绪，也成了对方可以计算和利用的素材。**

“孙哥”只是一种虚构人物类型，不指向任何真人，也不代表对真人作事实指控。

## 输入

至少需要原文链接、正文或文档之一，并让用户选择：

- **沿用原文事实**：只改叙述视角，不添加原文没有的事件；
- **重新创作虚构故事**：只借用写法，人物与事件全部虚构。

用户可以补充女性角色、关系场景和希望保留的数字或物件。材料不足时，只追问会改变成文结果的信息。

## 第一步：找出三个“孙学机关”

先用普通人能看懂的话指出原文最重要的三个机关：

1. **数字锚点**：钱、天数、次数、人数、秒数、额度与截止点分别在证明什么。
2. **物件回声**：哪些普通物件反复出现，并承担权力、亲密或风险含义。
3. **谁在定价**：谁能调动钱、信息和时间；谁只能等待；最后又是谁决定这段关系怎样被讲出去。

区分原文明确事实、叙述者判断、无法确认的空白。不得把判断写成事实。

## 第二步：建立女性认知账本

女性角色不能只是“受伤的人”。她必须有自己的算法：

- 计算身体成本、时间、劳动、注意力、机会成本和退出代价；
- 相信自己在测试底线、给关系定价或保留退路；
- 分开列出她知道什么、不知道什么、误判了什么；
- 通过数字、物件和行为表达判断，少用直接情绪说明。

在内部建立账本：`她投入了什么 / 她想验证什么 / 她以为控制了什么 / 实际被谁定义`。默认不把这张方法表整页展示给用户。

## 第三步：设计反转

先写 6—10 个节拍，再成文。结尾必须满足：

- 反转有前文埋伏，不靠突然宣布“她被收割了”；
- 用可见证据完成揭示，例如一段沉默、一个数字变化、一次转述、一个公开标题或一个被再次利用的物件；
- 她发现自己不仅损失金钱或感情，还可能被转化成谈资、内容、信誉或注意力；
- 保留她的主体性：她能看懂这件事并决定下一步。

## 第四步：写成文章

- 女性第一人称，短段落，克制、准确、少解释；
- 数字不是装饰，每个数字都推进关系或权力变化；
- 关键物件至少出现两次，第二次含义改变；
- 每段尽量不超过四行；全文优先控制在 1200—2500 字；
- 不照搬原文句式，不假冒真实人物自述，不虚构可被误认成新闻事实的细节；
- “孙学”指结构写法，不代表对任何真人作事实指控。

## 默认交付

1. **三个孙学机关**：每个用一两句话说明；
2. **女性反转大纲**：6—10 个节拍；
3. **完整文章**：女性有判断、有行动，不靠卖惨完成反转。

事实、推断与虚构核对在后台完成；只有发现风险时才展示。只有用户明确需要时，才补充场景图、阅读页或发布素材；不自动上传或发布。

## 安全与事实边界

- 涉及公众人物或现实争议时，必须显著标注虚构，不把私生活指控写成事实；
- 保留原文出处，短引文必须克制，优先概括；
- 不生成可识别真人面孔，不编造真实人物的私密信息或性内容；
- 不自动向 YouMind、X 或其他平台发布；
- 若原文事实无法核验，写“原文叙述称”，不要替原文背书。

## 完成检查

- [ ] 读者能看出她在计算什么，而不是只看见情绪
- [ ] 数字、物件和停顿都承担叙事功能
- [ ] 结尾由证据完成反转，不靠口号解释
- [ ] 女性仍有判断和行动，不被写成扁平受害者
- [ ] 事实、推断、虚构已分开
- [ ] 已注明虚构与原文出处
